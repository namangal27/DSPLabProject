# DSP Lab Project - Image Tampering Detection Using ELA

Image Tampering Detection and Localization using Error Level Analysis (ELA) in MATLAB.

## How to Run

1. Open MATLAB
2. Navigate to this project folder
3. Run:
   ```matlab
   run_project
   ```

## Files

- `generate_ela.m` - Core ELA function
- `run_project.m` - Main script to run the project
- `test.jpeg` - Original image
- `tampered.jpg` - Tampered image
- `Results/` - Output images from the detection pipeline
